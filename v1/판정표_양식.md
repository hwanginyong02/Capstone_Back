# 과잉 차단 판정표 양식 (사전 등록 v1)

파일: `04_판정표/판정표.csv` (UTF-8). 첫 줄은 열쇠 파일 sha256, 둘째 줄이 열 이름.

```text
# 열쇠 sha256: <64자리>
문항,표시 종류,표시된 문장,짝 문장(모순일 때),앞 문장,뒤 문장,판정자 사유,대상 필드,필드 값,판정(실제 오류/판정자 오판),판정 사유(필드 값과 함께 한 줄)
```

| 열 | 뜻 | 누가 채우나 |
|---|---|---|
| 문항 | 무작위 번호 J001… (시드 기록) | 도구 |
| 표시 종류 | 사실 일치 위반 / 단정형 추론 / 모순(값 불일치·판정↔권고·약점↔권고·분석↔소견) / 베이스라인 지적(시간이 남아 섞을 때 — 종류는 "지적"으로만 표기) | 도구 |
| 표시된 문장 | 판정자가 문제로 본 서술 문장 전문 | 도구 |
| 짝 문장 | 모순일 때 다른 쪽 문장 | 도구 |
| 앞 문장·뒤 문장 | 같은 칸 안의 앞뒤 문장(없으면 비움) | 도구 |
| 판정자 사유 | 주장 종류, 관계(같음/큼/작음 등), 판정자가 고른 대상과 그 근거 값 | 도구 |
| 대상 필드·필드 값 | 데이터에서 그 주장이 대조된 필드와 값 | 도구 |
| 판정 | 실제 오류 / 판정자 오판 | 판정 담당 |
| 판정 사유 | 필드 값과 함께 한 줄 | 판정 담당 |

- 싣지 않는 것: 문서 이름, 결과서 태그, 출처(원본·변형·결함본), 결함·변형 ID, 회차, 실행 번호.
- 열쇠(`04_판정표/열쇠/열쇠.csv`): 문항 → 묶인 표시 목록(실행 번호, 문서, 출처, 표시 순번). 읽기 전용, sha256 기록. 판정을 마칠 때까지 열지 않는다.
- 판정 기준: 표시된 문장이 대상 필드 값과 판정 기준 규칙(숫자 반올림 대조, 이름 대조, 비교 방향, 정도 표현, 추론 표시)에 비추어 실제로 틀렸으면 "실제 오류", 아니면 "판정자 오판".
